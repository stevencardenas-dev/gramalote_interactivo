# Backend

Carpeta reservada para la API de Gramalote Interactivo.

Pendiente de definir stack, modelo de datos y endpoints. Requerimientos ya
identificados en los briefs:

- Inventario de establecimientos con categorías (comer, dormir, comprar),
  ubicación en Gramalote Nuevo / Viejo, horarios y estado de apertura.
- Experiencias con galería, datos prácticos y recomendaciones.
- Contenidos de historia, curiosidades e información práctica.
- Buscador global (lugares, productos, contenidos históricos).
- Autenticación para el panel de administración.
- API de mapa con filtros por categoría.
